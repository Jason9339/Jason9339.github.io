**Code:** [GitHub](https://github.com/EricLiu750501/HCI-FinalProject)

A desktop tool that helps users learn sequences of hand gestures through a webcam.
Users can record new gestures, check that each gesture is recognized correctly, compose gestures into named sequences, and start a practice session by saying the sequence's name; on-screen prompts then guide them through each step.
The system uses MediaPipe and a YOLOX hand detector for recognition and speech recognition for voice commands.
